# Исходный код (source)

Данный каталог нужен для соответствия требованию о хранении исходников проекта
на сервере в папке `source`.

Серверная часть «Кухни мира» (Модуль Б) реализована как полноценный проект
**Laravel** и находится в корне этого репозитория:

* `app/` — контроллеры, модели, сервисы, middleware, FormRequest, API-ресурсы;
* `routes/` — маршруты (`web.php`, `api.php`, `channels.php`);
* `resources/views/` — Blade-шаблоны админ-панели;
* `database/` — миграции и сидеры.

Клиентское SPA (Модуль В) при необходимости размещается в отдельном каталоге
`source` и подключается к API по адресу `{{site-url}}/recipe-api/`.
