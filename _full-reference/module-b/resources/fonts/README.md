# Шрифты для водяных знаков

В каталоге размещены TTF-шрифты, используемые сервисом `App\Services\ImageService`
для нанесения водяного знака (названия рецепта) на миниатюры:

* `verdana.ttf`
* `arial.ttf`

`ImageService` выбирает первый доступный шрифт из списка (сначала ищет в этом каталоге,
затем — в системных каталогах). Если TTF-шрифт не найден, используется встроенный
растровый шрифт GD (резервный вариант).

Путь к собственному шрифту можно задать переменной окружения `WATERMARK_FONT`.
