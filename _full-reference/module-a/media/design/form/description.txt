ОПИСАНИЕ ДИЗАЙН-МАКЕТА ФОРМЫ «ПРЕДЛОЖИТЬ ИСПРАВЛЕНИЕ»
Файл макета: media/design/form.png
Назначение: форма на странице достопримечательности (landmark.html), id="correction-form".

ОБЩИЕ ПАРАМЕТРЫ
- Фон страницы: светлый, #F6F3EC. Карточка формы: белая, #FFFFFF.
- Граница карточки: 2px, цвет #DFD9CC, скругление углов 12px.
- Внутренние отступы карточки: 40px по горизонтали и вертикали.
- Тень: мягкая (0 6px 18px rgba(20,40,30,.12)).

ЗАГОЛОВОК
- Слева — круглая иконка-подсказка (диаметр 46px) с символом «?», цвет фона — акцентный зелёный #1F6B4A, символ белый.
- Заголовок «Предложить исправление»: шрифт с засечками (Site Serif), размер 24px, цвет #1E2A24.
- Подзаголовок «Помогите сделать информацию точнее»: шрифт без засечек (Site Sans), размер 13px, цвет #5E6B63.

ПОЛЯ (порядок сверху вниз, все — на всю ширину)
1. Имя пользователя — текстовое поле, placeholder «Иван Петров».
2. E-mail для обратной связи — поле типа email, placeholder «you@example.com».
3. Тип исправления — выпадающий список со значениями: «Неточность в описании»,
   «Устаревшие данные», «Некорректные координаты», «Некачественное фото», «Другое».
4. Описание предлагаемого исправления — многострочное поле, placeholder «Опишите, что нужно исправить...».
5. Подтверждающее фото — зона загрузки файла (пунктирная рамка), подпись «Перетащите файл или нажмите для выбора (jpg, png, до 5 Мб)».
6. Чекбокс «Согласен на обработку персональных данных».
7. Кнопка «Отправить» — широкая, с закруглёнными углами, цвет #1F6B4A, белый текст.

СТИЛИ ПОЛЕЙ
- Граница полей: 2px, цвет #DFD9CC, скругление 6px.
- Фокус: граница #1F6B4A, свечение (box-shadow) rgba(31,107,74,.18).
- Текст метки: полужирный, 14px, цвет #1E2A24. Обязательные поля помечены «*» цветом #C0392B.
- Отступы между полями: 34px.
- Placeholder: цвет #5E6B63.

СООБЩЕНИЯ ВАЛИДАЦИИ
- Под полем выводится сообщение об ошибке (цвет #C0392B), при корректном заполнении — зелёное сообщение #2E7D32.
- Поле с ошибкой подсвечивается красной границей.
