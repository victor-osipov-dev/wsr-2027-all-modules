# Модуль А — «Разработка интерфейса пользователя»

Статическая вёрстка платформы **«Открой Оренбуржье»** (достопримечательности Оренбургской области).
Стек: **HTML + CSS** (без JavaScript и без CSS-фреймворков — согласно заданию).

## Как запустить

Скопируйте содержимое папки `module-a` в корень веб-сервера (документ-рут) так, чтобы сайт открывался по адресу
`http://xxxxxx-m1.web.lan/index.html`. Никаких сборщиков и зависимостей не требуется.

## Структура проекта

```
module-a/
├── index.html          — главная (светлая тема)
├── index_dark.html     — главная (тёмная тема)
├── catalog.html        — каталог достопримечательностей
├── login.html          — вход
├── register.html       — регистрация
├── profile.html        — личный кабинет
├── landmark.html       — страница достопримечательности
├── admin.html          — административная панель
├── css/
│   ├── base.css        — токены, сброс, типографика, формы, кнопки
│   ├── layout.css      — контейнер, шапка, навигация/бургер, сетки, подвал
│   ├── components.css  — карточки, слайдер (CSS-only), статусы, отзывы, анимации
│   ├── pages.css       — стили страниц (авторизация, кабинет, достопримечательность, админка)
│   └── print.css       — стили печати
└── media/
    ├── logo.png, favicon.png, colors.png
    ├── fonts/          — локальные шрифты (@font-face)
    ├── img/            — фотографии, иконки (SVG), логотипы партнёров
    └── design/         — макет формы «Предложить исправление» + описание
```

## Ключевые особенности реализации

- **Без JavaScript.** Бургер-меню, слайдер, переключатель темы и сообщения валидации
  реализованы только средствами CSS (`:checked`, `:has()`, `:valid`/`:invalid`).
- **Адаптивность.** Более 4 структурных изменений при переходе 1920px → 360px
  (меню → бургер, сетки 5/4/3/2 → 1 колонка, подвал 3 → 1 колонка, двухколоночные формы → одна колонка).
- **Темы.** Светлая по умолчанию; тёмная — страница `index_dark.html` (класс `theme-dark`) и переключатель
  в личном кабинете. Между темами более 4 визуальных отличий.
- **Печать.** При печати `landmark.html` остаются только название, чёрно-белое изображение и заголовок
  «Добро пожаловать!» (шапка, подвал и форма скрываются).
- **Сообщения форм** для регистрации и формы исправления показываются для трёх ситуаций:
  незаполненное поле, некорректные данные, корректные данные (поля подсвечиваются).
