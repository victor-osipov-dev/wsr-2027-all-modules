# Конкурсное задание «Веб-технологии» — минимальное решение (3 модуля)

В репозитории два варианта решения:

| Папка | Что это | Зачем |
|-------|---------|-------|
| **`module-a`, `module-b`, `module-v`** | **Минимальная версия** — тот объём, который реально написать руками за 12 ч (3 × 4 ч) | основной рабочий вариант |
| `_full-reference/` | Полная версия (максимум функционала, ~17 000 строк) | архив/подстраховка, на конкурсе не воспроизводится |
| `spec/` | Тексты задания и критериев | справка |
| `PLAN-MINIMAL.md`, `plan-minimal.csv` | План «что успеть за 4 ч на модуль» и сколько это баллов | планирование |
| `TIME_ESTIMATE.md`, `file-time-estimate.csv` | Строгая оценка времени по каждому файлу (полная версия) | анализ |
| `MODULE-B-4H.md` | Разбор Модуля Б по критериям: что даёт баллы, что выброшено | анализ |

Принцип минимальной версии: **максимум баллов за минимум ручного кода**, без абстракций
и переиспользуемых обёрток.

## Текущие размеры (свои файлы, без пробелов/переносов)

| Модуль | Файлов | Строк | Непробельных символов |
|---|---:|---:|---:|
| А — HTML/CSS | 9 | 1 598 | 36 513 |
| Б — Laravel + API | 23 | 1 514 | 47 556 |
| В — Vue SPA | 13 | 749 | 20 063 |
| **Всего** | **45** | **3 861** | **≈104 100** |

Строки посчитаны **после форматирования** (отступ 4 пробела, каждый атрибут на своей строке),
поэтому по объёму кода ориентир — непробельные символы. Не считаются `vendor/`, `node_modules/`,
`dist/`, `.git/`, скаффолды `config/` и lock-файлы.

## Модуль А — `module-a/` (HTML + CSS)

7 страниц: `index.html`, `index_dark.html`, `login.html`, `register.html`, `profile.html`,
`landmark.html`, `admin.html`. Два CSS-файла (`css/site.css`, `css/print.css`), медиа — в `media/`.

Лёгкие приёмы:
- один каркас (шапка/подвал/меню) копируется на все страницы;
- тёмная тема — копия главной + класс `dark` на `<html>`;
- бургер, слайдер, переключатель темы, сообщения форм, анимация — **только CSS** (без JS);
- подсказки поиска — `<datalist>`; печать — `@media print`.

Итого **9 файлов, ~1 600 строк (~36 500 непробельных символов)**; повторяются только шапка/подвал.

## Модуль Б — `module-b/` (Laravel 12 + MySQL)

Вся логика — в 2 контроллерах (админка + API), без сервисов/ресурсов/FormRequest.
Скелет Laravel и `vendor/` создаются генератором (`composer create-project`, `artisan make:*`).

Итого **23 своих файла, ~1 510 строк (~47 600 непробельных символов)**
(контроллеры 637, Blade 347, БД 261, модели 134, роуты/каркас ~135). Разбор по критериям — в [`MODULE-B-4H.md`](MODULE-B-4H.md).

## Модуль В — `module-v/` (Vue 3 + Vite)

Один `src/api.js` (axios + заголовок `Client` + Bearer), роутер, 7 экранов-компонентов.
Никаких `components/`, `composables/`, `stores/`, `utils/` — обычные `v-model` и логика прямо в компонентах.

Итого **13 файлов, ~750 строк (~20 000 непробельных символов)**.

## Развёртывание

- **А:** содержимое `module-a/` → корень веб-сервера.
- **Б:** `composer install` → `.env` → `php artisan key:generate` → `migrate --seed` → `storage:link` (документ-рут → `public/`).
  Учётные записи: `admin@champ2026.lan` / `champ2026`, `user@champ2026.lan` / `Champ2026`.
- **В:** в `module-v/source/.env` задать `VITE_CLIENT_LOGIN=<логин>`, затем `npm install && npm run build`; `dist/` на хост, исходники — в папку `source`.
